# ภาพหน้าจอโปรเจกต์

เพิ่มภาพหน้าจอจริงของเว็บไซต์ลงในโฟลเดอร์นี้ แล้วนำไปแสดงในตารางภาพตัวอย่างของ [README หลัก](../../README.md)

| ชื่อไฟล์ | ภาพที่แนะนำ |
| --- | --- |
| `home.webp` | หน้าแรก |
| `reading.webp` | หน้าเลือกหรือเปิดไพ่ |
| `analytics.webp` | หน้าสถิติของผู้ดูแล โดยไม่แสดงข้อมูลส่วนตัว |
